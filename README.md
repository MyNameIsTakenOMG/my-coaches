# Socio-Technical Architecture Coach Agent Skill

A deliberate practice engine built as an agent skill. This coach guides learners step-by-step through a complete socio-technical systems analysis loop without giving away the answers.

## 🎯 Project Purpose

The primary goal of this repository is **not just the final artifact, but the journey**. This project was built entirely using the socio-technical approach it teaches, documenting every strategic decision, system flow analysis, and tactical boundary choice along the way.

- **The Execution Blueprint:** View the core agent prompt definition in [SKILL.md](coaches/socio-technical-coach/SKILL.md).
- **The State Engine:** Inspect the markdown schema used to handle long-term context retention in [practice-note-template.md](coaches/socio-technical-coach/practice-note-template.md).
